# Algal Engineering Ltd. — Website (preview)

Single-file website: `index.html` (logo, fonts and code bundled). Project photos load from algal.ca.

## Publish with GitHub Pages
1. Upload `index.html` to the root of the repository (Add file → Upload files → Commit).
2. Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / `(root)` → Save.
3. After 1–2 minutes the site is live at `https://algalengineering.github.io/algalengineering/`.
